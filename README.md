# Calculadora web

Pequeño proyecto de una calculadora funcional hecha con HTML, CSS y JavaScript.

## Características
- Operaciones básicas: suma, resta, multiplicación y división
- Diseño simple y responsivo
- Funciona directamente en el navegador

## Estructura de archivos
- `index.html` — estructura de la interfaz
- `style.css` — estilos visuales
- `index.js` — lógica de la calculadora

## Cómo usar
1. Abre `index.html` en tu navegador.
2. Usa los botones para realizar operaciones.
3. Puedes modificar el diseño o agregar nuevas funciones.
